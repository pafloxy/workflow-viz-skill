# Agent handoff

## Start here

Read this file, then SKILL.md, before doing substantive code, proof, writing, review, or release work in this repository.

## Product

Modular View Skill is a static text skill. Its job is to help an agent explain bounded structure through compact terminal maps while preserving source fidelity, relation meaning, evidence status, and the requested deliverable.

## Task branches

### Explain

Read the relevant source, show the smallest useful map, distinguish observed facts from proposals, and provide the requested explanation.

### Change the skill or examples

Read SKILL.md and the affected examples. Preserve the static-only product boundary, stable IDs, directed relation semantics, and the distinction between containment, dependency, support, and reading order. Update the relevant evaluation record when a behavior claim changes.

### Release

Review LICENSE, README.md, RELEASE.md, and the evaluation records. Confirm that every tracked file is intentional public content, that links and JSON parse, and that release claims match recorded evidence.

## Completion

Finish with a compact final map, exact checks run, changed files, and stated limits. Do not represent an unchecked claim as verified.
